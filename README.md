# Wobble Rush

An original Roblox party-royale for up to 30 players. Round, squishy **Bloblets** wobble through
randomly shuffled mini-game rounds until one winner is left.

This repository is a [Rojo](https://rojo.space) project: all game code is Luau in `src/`, and
Rojo syncs it into Roblox Studio. The lobby, characters and UI are all generated by code, so
there are no models or images to upload.

## 1. Connecting Rojo to Roblox Studio

You need three things: this folder on your computer, the Rojo command-line tool, and the Rojo
plugin inside Studio.

### Get the code

```bash
git clone https://github.com/eminhqn/rblxfllgys.git
cd rblxfllgys
```

### Install Rojo (choose one)

**Option A: VS Code (easiest)**
1. Install [Visual Studio Code](https://code.visualstudio.com/) and open this folder in it.
2. Accept the "recommended extensions" prompt. That installs Rojo, Luau Language Server,
   StyLua and Selene (listed in `.vscode/extensions.json`).
3. Open the command palette (`Ctrl+Shift+P`) and run **Rojo: Open Menu**. It will offer to
   install Rojo and the Studio plugin for you.

**Option B: Rokit (command line)**
1. Install [Rokit](https://github.com/rojo-rbx/rokit).
2. In this folder run `rokit install`. That installs the exact tool versions in `rokit.toml`
   (Rojo 7.7.1, Selene, StyLua, luau-lsp).
3. Run `rojo plugin install` to add the Rojo plugin to Studio.

### First time: build the place file

Some settings (streaming, lighting, "don't load the default avatar") can't be changed by live
sync, so build the place once and open it:

```bash
rojo build -o WobbleRush.rbxl
```

Open `WobbleRush.rbxl` in Roblox Studio, then **File → Save to Roblox** if you want it in your
account. You only need to rebuild if `default.project.json` changes.

### Every session: live sync

1. In the terminal (or the VS Code Rojo menu): `rojo serve`
2. In Studio: **Plugins** tab → **Rojo** → **Connect** (default `localhost:34872`).
3. Edit files in `src/`. Changes appear in Studio straight away.

> Always edit the code in `src/`, not inside Studio. Rojo overwrites script changes made in
> Studio.

## 2. Testing Milestone 1 in Studio

Press **Play** (F5) for a solo test. For grabbing and team checks, use **Test** tab →
**Clients and Servers** → choose **2–3 players** → **Start**.

Keep the **Output** window open (View → Output). There should be no red errors.

### Checklist

**Spawning and lobby**
- [ ] You spawn on your team's raised deck as a Bloblet (round body, cartoon eyes, stubby arms,
      floppy feet). Your normal Roblox avatar does not appear.
- [ ] The top of the screen shows the **WOBBLE RUSH** badge and a chip with your team name.
- [ ] You (and others) have a thin outline in the team colour.
- [ ] Each deck has tinted glass walls, a team sign and four spawn pads. You can walk down the
      stairs to the plaza and back up.
- [ ] The big screen at the far end shows `players / 30` and per-team counts. With several test
      players, the counts update as players join and leave.

**Movement feel**
- [ ] WASD ramps up smoothly, stops quickly and turns sharply. The body leans into the movement.
- [ ] Tap Space for a short hop, hold it for a full jump.
- [ ] **Coyote time:** run off the edge of a foam step and press jump just after leaving it. You
      still jump.
- [ ] **Jump buffering:** press jump just before you land. You jump again the moment you touch
      down.
- [ ] Squash on landing (with a jelly wobble), stretch in the air, idle breathing, blinking, and
      eyes that look where you're moving.

**Moves**
- [ ] **Dive** (Ctrl or C): belly-flop forward. Steer it a little in mid-air with the stick or
      keys. You land in a short slide you can steer, and **pressing jump during the slide cancels
      it into a jump that keeps the dive's speed**. Roughly a 1 s cooldown.
- [ ] **Air control:** you can change direction and stop in mid-air easily.
- [ ] Practice course (right side): climb the three foam steps and **jump, then dive** across
      the gap. A jump alone falls short.
- [ ] **Bounce pad** (left side): launches you high. Steer onto the floating platform.
- [ ] **Spinner** (centre): getting hit near the end of the bar knocks you over. You tumble, the
      camera shakes, your eyes spin, and you get up after 1–2 s. Near the hub it only pushes you.
      You can jump over the bar.
- [ ] **Grab** (hold Shift or E, 2+ players): face another Bloblet up close and hold. They slow
      down and get tugged towards you, and their eyes go wide. Let go to release. It auto-releases
      after 3 s or if you get too far apart.

**Devices**
- [ ] **Mobile:** Test tab → Device → pick a phone. A thumbstick appears where you touch on the
      left, and Jump / Dive / Grab buttons on the right. The Dive button darkens while cooling
      down. The keyboard hint is hidden.
- [ ] **Gamepad:** plug one in. The controls card switches to gamepad buttons (A jump, X dive,
      R2 grab, left stick move).
- [ ] UI stays readable when you resize the Studio window.

**Safety nets**
- [ ] Esc → **Reset Character** gives you a fresh Bloblet on your deck.
- [ ] Jump over the plaza bumpers and walk far away. You are respawned once you're about 420
      studs from the centre.

If something feels off, most of the feel is tunable in `src/shared/Config.luau` (speeds,
acceleration, jump height, coyote and buffer windows, dive, grab and ragdoll values).

## 4. How it's built

```
src/
  shared/   (ReplicatedStorage.Shared)            used by server and client
    Config        all tuning numbers; the server validates with the same values
    BlobletRig    builds the Bloblet model in code
    Remotes       creates/gets the RemoteEvents
    Teams, Theme, Ui, Tags, HazardMath, MathUtil, Signal
  server/   (ServerScriptService.Server)
    Main.server   starts the services in order
    Services/     CharacterService, TeamService, ActionService, MovementValidator,
                  LobbyService, PlayerState, EnvironmentService
    Builders/     LobbyBuilder, Backdrop, Geometry (rounded "inflatable" parts)
  client/   (StarterPlayerScripts.Client)
    Main.client   starts the controllers
    Controllers/  InputController, TouchControls, MovementController, BlobletAnimator,
                  HazardController, TeamOutlines, CameraFX, Sfx, Hud, ResponsiveScale
```

**Who decides what**
- **Movement** runs on your own device (Roblox gives each player ownership of their character's
  physics), so it responds instantly. The server checks positions twice a second and snaps back
  impossible speed or teleports (`MovementValidator`).
- **Dive and grab** play instantly on your screen, and a request goes to the server. The server
  checks cooldowns and state, picks the grab target itself, and publishes the result as
  character attributes (`Action`, `Grabbing`, `GrabbedBy`, `Ragdolled`). Other clients animate
  from those. Rejected requests cancel the local prediction.
- **Every remote** is rate-limited and type-checked on the server (`ActionService`,
  `CharacterService`). Clients only send intent, never results.
- **Moving hazards** are animated on each client from the shared server clock, so the server
  sends no per-frame data. Everyone sees the same pose, and hits are judged against what you
  actually see.
- **Animation** (squash/stretch, eyes, feet) is client-only via `Motor6D.Transform` and
  `SpecialMesh.Scale`, with distance-based detail reduction for 30 players.

**Adding things later**
- New hazards: tag a model `Spinner` (with `Speed`/`Phase` attributes, a `Hub` and an `Arm`) or
  a part `BouncePad` (with a `Power` attribute), and the client picks it up automatically.
- Sounds: `src/client/Controllers/Sfx.luau` has a hook per sound. Grab and UI clicks are silent
  until you add an uploaded sound ID. The others reuse built-in Roblox sounds.

## 5. Development checks

These run without Studio:

```bash
rojo build -o WobbleRush.rbxl                     # project builds
rojo sourcemap default.project.json -o sourcemap.json
luau-lsp analyze --platform=roblox --sourcemap=sourcemap.json \
  --definitions=globalTypes.d.luau src            # strict type check (see below for definitions)
selene src                                        # lint
stylua --check src                                # formatting
```

`globalTypes.d.luau` is the Roblox API type definition file from the
[luau-lsp repository](https://github.com/JohnnyMorganz/luau-lsp/tree/main/scripts)
(`globalTypes.None.d.luau`). The VS Code extension downloads it automatically.
